一句话总结 · 最感动的3点

一句话总结

罪的荒谬，是人宁可扭曲真理也不肯降服基督；恩典的奇妙，是基督为这样的罪人受审受死，并赐新心使我们听见真理、悔改归向他。

1恩典没有被敌意堵住

他们去捉拿生命的主，主仍邀请干渴的人来。人的恶意没有使恩典失语。

2一个公正的问题也算数

圈子用嘲讽封口时，神仍使用一个要求先听的声音。勇气可以从很小的地方开始。

3受审者成为拯救者

本该受审的是我们。无罪的基督担当刑罚，又用圣灵救人脱离荒谬。

两幕一镜一主：
差役受讥，尼哥底母受辱；照见我心；归向基督。

四字诀：听 — 查 — 判 — 改

听
听本人。不先听口供，不知道所做的事，就不是律法的定罪（约7:51）。
查
查事实。细细探听（申17:4）。叫别人查考之前，先让圣经查考自己。
判
按圣经公正判断。不看外貌，也不把圈子的声望当成终审（申1:16–17）。
改
被真理纠正就悔改。这是感恩的操练，不是重生或称义的方法。

藏头「听查判改」可以这样记

听：差役听见了 查：尼哥底母要求查 判：领袖先判后听 改：十字架叫我能认错

四字本身是中文口诀，不是经文原句。

四个闭环（短句）

救赎历史

顺服 → 篡夺判断 → 律法与应许 → 基督被拒、受死复活 → 圣灵 → 等候更新。

圣约

神先说话 → 子民当听从 → 特权遮不住悖逆 → 中保担当 → 圣灵赐信 → 忠诚的生活。

圣经神学

智慧与愚昧 → 欲望或自义 → 光在基督里 → 十字架看似愚拙 → 在他里面重新学习判断。

罪—救赎—感恩

用标签躲避 → 基督担当、圣灵回转 → 不再靠赢争论 → 听查判改。

谁该作最终标准？点击翻面
神的道，不是圈子的声望。职分要服事道，不能代替道。
人最需要哪种更新？点击翻面
不只增加资料，更需要圣灵赐新心。圣灵藉福音做工，并不废掉研读。
我为什么可以认错？点击翻面
我的义在基督里，不在「从未被人指出错误」。认错是赦免的果子。
公正聆听是否等于认同？点击翻面
不是。先听、查清，是为了能够正确判断，不是为了同意每一句话。
差役的惊叹等于得救吗？点击翻面
不等于。经文没有写下他们的结局。真信心是信靠基督，不只是觉得话动听。
约7:52可以怎样讲才稳妥？点击翻面
约拿是有力的反例之一，但时态与「那先知」的少数读法要说明。无论如何，他们没有回答「先听本人」。
