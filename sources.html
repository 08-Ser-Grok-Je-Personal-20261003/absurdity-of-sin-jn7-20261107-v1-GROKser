怎样保证逐字

  1. 只注入，不手打信条。三大信经、海德堡要理问答、比利时信条、多特信经来自 data/bop.json（由 ccifellowship.org 页面解析）。和合本来自 getbible.net 的 cus。讲章里的引句用宏生成；构建时若片段不是来源的子串，构建会失败。
  2. 再独立抓一次。tools/verify.py 在线重抓相关页面，把站内文字块与引句去掉脚注号、标签和空白后比对。

自行复核：python3 tools/verify.py，然后 python3 tools/build.py，把报告写入本页。结果文件是 reports/verify.json 与 reports/verify.txt。

没有当作引文的内容

以下是整理，不是逐字引文
  • 作者与年代。第四福音的传统归属、公元80–100年的常见判断、较早说法、受难年份的两说，都是一般圣经背景。书中明确的目的句与见证句（约20:30–31；21:24）才用和合本注入。
  • 受众。不能把读者锁定为某一个已被证实的地方群体。
  • 职分与节期。差役不等于现代警察；祭司长与法利赛人不是同一群体；7:45–52不是已经正式开庭的全体公会审判。住棚节的旧约依据是一般知识。本站没有把《密西拿》的礼仪句子当成引文。
  • 迦特希弗。王下14:25写明约拿是迦特希弗人。将该城辨认为后来的加利利城邑，是通常说法；精确遗址仍有讨论。地图上的点只表示「在加利利框内」。
  • 约7:52的希腊文。时态以及极少数抄本读作「那先知」，是释经讨论里应当提起的警戒，避免把讲道押在「他们忘了约拿」。本站没有抓取希腊文辞典，也没有把某一注释页的句子抄进来。内容草稿曾提到 IVP 新约背景注释与 translation.bible 的说明页；那些页面不是本站的引文来源，其中如「差役离开了四天」之类的推测也没有采用。
  • 抄本。行淫妇人叙述在古抄本中的有无与位置有差异。本站电子和合本把相关文字放在约8:1–11，第7章止于52节；有的印刷本从7:53编起。论证不依赖这段。
  • 威斯敏斯特信条与小要理。只在信条精选作意译，无引号，未抓取原文。
  • 诗歌。圣诗第4首、第9首，韵诗11篇、7篇、第1篇，只列编号。韵诗与诗篇篇号的对应是假定，已在诗歌页声明。所附诗篇是和合本经文，不是歌词。
  • 三大信经的其他中文译本可能用字不同。本站只采用 ccifellowship.org 的文本。
源站简介里的一处编号

ccifellowship.org 对亚他那修信经的简介称第二部分包括第29–43点，正文编号止于第42点。本站照录，不自行改正。正文与简介在信经页都看得到。

使用上的限制

  • 示意图的箭头不是住棚节的实测路线。经文没有写下差役走路的细节。
  • 成书年代并列不同看法，讲章论点不挂在某一年上。
  • 朗读使用浏览器的语音合成，站内没有录音。
  • 若 ccifellowship.org 日后改字，请重跑抓取与 tools/verify.py。
  • 站点可放在仓库根目录，也可放在 GitHub Pages 这类子路径下：页面与样式都用相对链接。
